## Commit message types

1. Feat Commits that add, adjust or remove a feature to/of/from the API or UI

Example: git commit -m "feat: xxxxxx"

-------------------------

3. Fix Commits that fix an API or UI bug of a preceded feat commit

Example: git commit -m "Fix: xxxxxx"

-------------------------

5. Style Commits that address code style (e.g., white-space, formatting, missing semi-colons) and do not affect application behavior

Example: git commit -m "Style: xxxxxx"

-------------------------

7. Test Commits that add missing tests or correct existing ones

Example: git commit -m "Test: xxxxxx"

-----------------------
